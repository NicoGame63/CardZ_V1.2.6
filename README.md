# CardZ — 废土卡牌地牢

一个纯前端、无需构建工具的废土卡牌地牢小游戏。玩家在 5×5 棋盘中移动、收集瓶盖、装备武器、处理陷阱和怪物，并通过最高分解锁英雄。

## 本版改动

- ~~医师完全免疫中毒 Debuff~~（**已在下方"本次改动"中调整**）：医师不再是全局免疫中毒，仅能识破伪装成药水的毒药水陷阱。
- **修复生命核心重复回血**：旧逻辑同时执行 `heal +4` 和“最大生命提高时当前生命 +4”，实际会一次回复 8 点。现在生命核心只执行一次当前生命 +4，同时临时最大生命 +4，持续随机 5–8 回合。
- **修复第二局进入后棋盘不显示**：第一局死亡结算若发生在 Canvas 动画结束回调中，旧渲染流程会在同一帧继续读取已经清空的游戏状态并抛异常，导致 `requestAnimationFrame` 主循环永久停止。现在动画回调延迟到本帧绘制结束后执行，同时主循环会先预约下一帧，第二局无需刷新网页即可正常显示。
- **新一局清理旧动画状态**：开始新游戏时会清空上一局残留的动画、飘字与粒子，避免上一局的延迟回调污染第二局状态。
- **加强空状态视野容错**：游戏结束后的短暂空状态下，视野查询会安全返回不可见，而不是访问空对象报错。
- **生命上限改为限时状态**：生命核心不再永久提高最大生命；每张生命核心会随机获得 **5–8 回合**持续时间。临时最大生命可叠加，状态栏显示 `生命上限 +数值（X回合）`，到期后最大生命恢复并将当前生命截断到新的上限。
- **旧生命上限存档自动迁移**：旧存档中高于英雄基础值的永久最大生命会自动识别为临时生命上限，并转换成 5 回合剩余时间，避免继续永久保留。
- **修复信标少 1 回合**：拾取 5 回合信标的当前移动不再立刻扣除 1 回合，状态栏会先完整显示 5 回合，从下一次成功移动开始倒计时。
- **修复绊索触发时机**：绊索现在真正作用于“下一次成功移动”；踩到绊索的当前移动仍正常推格，不再提前消耗效果。
- **修复远程击杀错误中毒**：毒雾怪、腐化僵尸的中毒属于接触击杀效果，远程射杀不再让玩家中毒。
- **加强损坏存档校验**：继续冒险前会检查玩家坐标是否越界、棋盘中是否存在未知卡牌，以及关键战斗字段是否为有效数字。
- **攻击力加成改为限时状态**：兴奋剂、能量饮料以及近战击杀虫群获得的攻击加成都不再永久生效，统一为临时增益。当前规则为持续 **5 回合**；同类增益仍可叠加数值，并刷新剩余持续时间。
- **状态栏显示攻击增益剩余回合**：攻击状态显示为 `+数值（X回合）`，每完成一次移动回合减少 1；刚获得增益的那个移动回合不会立即扣除持续时间。
- **旧存档兼容**：旧版本存档若带有永久 `atkBuff`，载入时会自动转换成最多 5 回合的临时攻击增益，避免旧存档绕过新的平衡规则。
- **卡牌图鉴补全说明**：已收录卡牌会在卡图下方显示生命、掉落、耐久、治疗、护盾、中毒、特殊效果等实际规则；数值区间直接来自卡牌定义。
- **远程武器受视野限制**：左轮、弩等远程武器只能攻击当前可见格中的敌人。迷雾中的敌人不会被瞄准高亮，也无法开火命中。
- **修复棋盘越界报错**：角色位于边缘时继续按方向键向棋盘外移动，不再访问不存在的数组格子。
- **修复弹药箱提示**：远程武器获得 `+5` 耐久后，不再被错误的“获得瓶盖”日志覆盖。
- **修复 HUD 武器点击**：顶部武器状态现在和下方状态栏一样可以点击进入/退出远程瞄准。
- **整理重复显示逻辑**：移除了 `game.js` 中重复的卡牌显示判定实现，减少两套逻辑以后发生偏差的风险。
- **修正默认主题解锁**：初始解锁主题改为 `wasteland`，而不是错误地默认解锁 200 分主题 `ruins`；旧存档会自动补上基础主题，不会删除已经解锁的内容。
- **增强存档容错**：损坏或结构不完整的本局存档不会再直接进入游戏并导致运行时异常。

## 运行方式

项目不需要 npm、打包器或后端。目录结构如下：

```text
CardZ-fixed/
├─ index.html
├─ README.md
├─ 代码说明.txt
├─ css/
│  └─ style.css
├─ js/
│  ├─ audio.js
│  ├─ cards.js
│  ├─ game.js
│  ├─ render.js
│  ├─ storage.js
│  ├─ textures.js
│  └─ ui.js
└─ assets/              # 可选
   ├─ cards/
   └─ heroes/
```

最简单的方式是直接打开 `index.html`。如果浏览器对本地资源有额外限制，也可以在项目目录启动一个静态服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 可选图片资源

游戏会尝试读取：

```text
assets/cards/<card-id>.png
assets/heroes/<hero-id>.png
```

没有这些图片也能正常运行，`textures.js` 会自动使用程序化绘制作为回退。

## 操作

- 鼠标/触屏：点击角色上下左右相邻格移动。
- `WASD` / 方向键：移动。
- `R`：装备远程武器时进入/退出瞄准。
- `F` 或空格：使用英雄主动技能。
- `Esc`：退出瞄准。
- 也可以点击 HUD/状态栏中的远程武器进入瞄准。

## 视野与远程攻击

普通英雄只能看到角色周围九宫格；游侠拥有全图视野，信标也能临时提供全图视野。

远程武器瞄准遵循同一套视野规则：

```text
合法远程目标 = 当前处于瞄准模式
             + 目标格在棋盘内
             + 目标格当前可见
             + 目标是怪物
```

因此普通英雄无法攻击迷雾中的敌人；游侠或处于信标全视野状态时，可以攻击全图可见的敌人。

## 临时攻击增益规则

当前会增加攻击力的卡牌效果均为临时状态：

- 兴奋剂：攻击 +2，持续 5 回合。
- 能量饮料：攻击 +2，持续 5 回合。
- 虫群：仅在近战击杀后攻击 +1，持续 5 回合。

多个攻击增益仍可叠加攻击数值；获得新的攻击增益时，会把剩余持续时间刷新到本次效果与当前剩余时间中的较大值。状态栏会显示类似 `攻击 +4（5回合）`。当剩余回合归零时，全部临时攻击加成立即清除，基础英雄攻击力不受影响。


## 临时生命上限规则

生命核心现在提供 `最大生命 +4`，并同步让当前生命 `+4`；这部分最大生命不再永久存在：

- 每张生命核心生成时独立随机 **5–8 回合**持续时间。
- 拾取生命核心的当前移动不消耗持续时间，从下一次成功移动后开始减少。
- 多次获得生命核心时，临时最大生命数值继续叠加；剩余时间刷新为当前剩余时间和新生命核心持续时间中的较大值。
- 状态栏会显示类似 `生命上限 +8（7回合）`。
- 持续时间归零后，全部临时最大生命一次性移除；如果当前生命高于恢复后的最大生命，只会截断到新上限，不会额外造成伤害或导致角色直接死亡。
- 旧存档里已经永久增加的最大生命，会在载入时转换为 5 回合临时状态。

## 医师抗毒规则（已更新，见下方"本次改动"）

医师拥有永久被动"识破毒药水"，它**不是**全局中毒免疫：

- 只有伪装成药水的**毒药水陷阱**不会让医师中毒（她能一眼识破）。
- 近战接触击杀毒雾怪、辐射丧尸等带毒怪物，以及踩到酸液罐，医师依然会正常中毒。
- 医师的主动技能"净化"用于随时清除当前已中毒的回合数，并回复生命——这是她应对怪物/酸液中毒的主要手段。
- 所有新增中毒统一通过 `addPoison()` 处理，通过 `canBeIdentified` 参数区分"可被医师识破的毒药水"与"普通中毒来源"；回合毒伤结算 `applyPoison()` 不再对医师做特殊豁免。

## 数据与存档

游戏通过浏览器 `localStorage` 保存数据：

- `cardz_meta_v1`：最高分、总局数、累计击杀、已收录卡牌、英雄与主题解锁。
- `cardz_save_v1`：当前冒险存档。
- `cardz_seen_help`：是否已经展示过首次新手引导。

清除浏览器站点数据会同时清除这些进度。

## 主要代码职责

- `cards.js`：难度、英雄、卡牌定义，随机实例生成，以及图鉴效果说明。
- `game.js`：移动、战斗、视野、远程瞄准、技能、推格、结算。
- `render.js`：Canvas 棋盘、迷雾、卡牌、瞄准高亮、动画与粒子。
- `ui.js`：菜单、HUD、图鉴、新手引导和输入绑定。
- `storage.js`：本局存档、长期进度、解锁与存档校验。
- `textures.js`：本地图片加载及无图片时的程序化回退绘制。
- `audio.js`：Web Audio 程序化音效。

## 本次改动（本地传送装置堆叠上限）

- **本地传送装置最多堆叠 3 个**：新增 `MAX_LOCAL_TELEPORT=3` 上限（与撬锁工具上限 5、护盾上限 15、技能充能上限 3 是同一套机制）。拾取时若已达上限会提示"装置已满"且不再增加数量；旧存档载入时如果数量超过 3，会自动截断到 3。状态栏与图鉴描述同步显示 `当前数量/上限`。

## 本次改动（HUD 战斗力显示 & 状态栏溢出修复）

- **HUD 生命值旁边的数值改为"战斗力"**：原来显示的是"当前武器耐久"，容易和实际战斗判定脱节（比如没有武器时显示"—"，但角色其实还有基础攻击力）。现在显示的是真正参与战斗判定的合计值：`英雄基础攻击 + 武器耐久 + 攻击增益 − 虚弱减益`（与 `game.js` 里 `power=S.weapon+S.atk+S.atkBuff-S.weakAtk` 完全一致，并做了下限 0 的保护），鼠标悬停/长按可以看到该数值的具体构成明细。
- **修复道具/状态栏被棋盘挡住的问题**：当状态栏（护盾、增益、道具、减益等）图标很多、需要换行显示时，原来的布局会让状态栏被挤压变形，其溢出内容视觉上被下方的棋盘盖住。现在状态栏改为固定不被压缩、拥有自己的最大高度并在超出后内部滚动（不会再侵占棋盘区域）；同时棋盘容器会通过 `ResizeObserver` 实时感知状态栏占用空间的变化并重新计算棋盘尺寸，避免棋盘尺寸与实际可用空间脱节导致的重叠。

## 本次改动（自爆者远程击杀爆炸伤害修正）

- **修复远程击杀自爆者仍受爆炸伤害**：自爆者死亡爆炸判定原来无条件对玩家造成伤害，导致远程武器在安全距离外击杀自爆者时玩家依然会挨炸。现在爆炸伤害只会在玩家处于自爆者周围九宫格（即 3×3 范围）内时才生效；不在爆炸范围内（例如隔着几格用左轮/弩远程点杀）不会受到任何爆炸伤害。周围怪物被炸死的效果不受影响，依旧作用于九宫格内的其他怪物。

## 本次改动（毒素与医师规则调整）

- **毒雾怪中毒时间调整**：近战接触击杀毒雾怪后，中毒回合数由固定 1 回合改为随机 **4–8 回合**。
- **辐射丧尸中毒时间调整**：近战接触击杀辐射丧尸后，中毒回合数由固定 2 回合改为随机 **3–6 回合**。
- **医师中毒规则改为"识破毒药水"而非全局免疫**：
  - 医师依旧能一眼识破伪装成药水的**毒药水陷阱**（`poison` 卡牌），踩到时完全不会中毒。
  - 医师击杀毒雾怪、辐射丧尸（含腐化僵尸等其他带毒怪物）时，**依然会正常中毒**。
  - 医师踩到**酸液罐**陷阱时，**依然会正常中毒**，无法识破或免疫。
  - 状态栏"抗毒"标签的说明文字调整为"识破毒药水"，不再显示为"免疫"，避免误解为全局免疫。
  - 这样一来，医师的主动技能"净化"（清除当前中毒并回血）才真正有存在意义，不会因为被动全免疫而变成摆设。
- **医师技能"净化"回血量提升**：主动技能净化的回血量由 4 点调整为 **6 点**（同时仍会清除当前全部中毒回合）。
- 旧存档载入时不再强制把医师的中毒回合清零——如果旧存档里医师身上确实带有中毒状态（例如中毒未消耗完），会按照新规则继续正常倒计时。
